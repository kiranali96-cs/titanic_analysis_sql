# Titanic Data Analysis Using SQL

## Project Overview

This project analyzes Titanic passenger data using MySQL Workbench.

## Objectives

- Analyze passengers by class (Pclass).
- Explore passenger ages.
- Analyze family members onboard using SibSp and Parch.
- Analyze boarding locations using Embarked.
- Explore passenger survival by class.

## Tools Used

- MySQL
- MySQL Workbench

## SQL Concepts

- SELECT
- WHERE
- COUNT()
- GROUP BY
- ORDER BY
- AVG()
- MAX()
- CASE statements

## Project Level

Beginner SQL Project
